# 旅行社行程执行单（导游任务单）分析报告

> 基于欧洲入境旅游行业标准实践，结合冠培作为奥地利持牌导游的实际经验

---

## 一、什么是行程执行单

行程执行单（也称导游任务单、地接执行单、Tour Voucher）是旅行社（组团社）发给地接导游的**正式工作指令**。它是导游出团的唯一依据，所有操作必须严格按此执行。

---

## 二、标准结构与字段

### 2.1 头部信息（Header）

| 字段 | 说明 | 示例 |
|------|------|------|
| 团号 | 唯一标识，贯穿全程 | `EU20260715-001` |
| 组团社名称 | 国内旅行社 | 北京凯撒国旅 |
| 地接社名称 | 欧洲当地旅行社 | 奥地利冠培旅行社 |
| 线路名称 | 产品线 | 德奥捷 10 天经典之旅 |
| 游客人数 | 成人/儿童/婴儿分开 | 25+1（25 客人+1 领队） |
| 导游姓名 | 地接导游 | 周冠培 |
| 领队姓名 | 国内随团领队 | 张某某 |
| 领队电话 | 联系方式 | +86 138xxxx |
| 司机姓名/电话 | 欧洲司机 | Thomas / +43 660 xxx |

### 2.2 航班信息

| 字段 | 说明 |
|------|------|
| 抵达航班号 | 接机用 |
| 抵达日期/时间 | 明确到分钟 |
| 抵达机场/航站楼 | 接机位置 |
| 离开航班号 | 送机用 |
| 离开日期/时间 | 明确到分钟 |
| 离开机场 | 送机位置 |
| 行李限额 | 每人托运/手提 |

### 2.3 酒店信息（逐晚列出）

| 字段 | 说明 |
|------|------|
| 城市 | 当晚所在城市 |
| 日期 | 入住日期 |
| 酒店名称 | 英文全称 |
| 酒店地址 | 完整地址 |
| 酒店电话 | 前台电话 |
| 房型 | 双人间/单人间数量 |
| 早餐 | 含早/不含早/早餐时间 |
| 入住/退房时间 | 酒店规定时间 |
| 备注 | 特殊要求（如加床） |

### 2.4 每日行程（逐日）

每一天通常包含：

| 字段 | 说明 |
|------|------|
| 日期 | 第 N 天 + 实际日期 |
| 城市 | 所在城市（可能有多个） |
| 上午活动 | 景点名称、游览时间、门票信息 |
| 午餐安排 | 餐厅名称、地址、电话、餐标、时间 |
| 下午活动 | 景点/购物/自由活动 |
| 晚餐安排 | 餐厅名称、地址、餐标、时间 |
| 酒店 | 当晚酒店 |
| 车程 | 城市间的行驶时间 |
| 自费项目 | 可选的自费项目列表 |
| 购物点 | 合作的购物点 |
| 导游备注 | 特殊注意事项 |

### 2.5 费用与结算

| 字段 | 说明 |
|------|------|
| 团款总额 | 总报价 |
| 已收定金 | 组团社已付 |
| 尾款结算方式 | 现金/转账/预付 |
| 导游备用金 | 导游携带的现金额度 |
| 门票预算 | 各景点门票总预算 |
| 餐费预算 | 每日餐标合计 |
| 特殊费用 | 过路费、停车费、小费等 |

### 2.6 特殊要求

| 字段 | 说明 |
|------|------|
| 客人特殊需求 | 素食、轮椅、过敏等 |
| VIP 服务要求 | 特定客人的高规格要求 |
| 应急联系方式 | 组团社紧急联系人、大使馆电话、保险电话 |
| 地接社紧急联系人 | 操作/计调电话 |

## 三、常见格式

旅行社行程单常见的三种格式：

### A. Word/PDF 表格（最正式）
- 标准 A4 纸张
- 表格形式，分节清晰
- 中英文双语
- 适合大型旅行社、正规团队

### B. 微信/邮件文本（最常见）
- 计调通过微信发文本
- 格式较随意
- 内容可能不全
- 导游需要自己补全信息

### C. Excel 电子表
- 操作方便、可筛选
- 多团并行管理
- 中小旅行社常用

## 四、冠培的实际场景推演

根据你的情况（奥地利持牌导游 + 自有旅行社），你的行程执行单可能来自两种渠道：

### 渠道 1：自己接团（冠培旅行社）
- 你自己就是地接社，行程你自己定
- 行程单可能是你自己写的
- 格式会规范很多
- **App 价值：** 自动整理、生成客户行程

### 渠道 2：接其他组团社的团
- 国内旅行社发来的执行单
- 格式五花八门（Word/PDF/微信文本）
- 关键信息可能分散在不同消息里
- **App 价值：** 扫描识别、统一结构化

## 五、对模板设计的关键启示

基于以上分析，JourneyWork 模型和模板系统需要覆盖的核心数据维度：

### 必填核心字段
```
团号 / 团名 → title
出团日期 → startDate / endDate
行程城市 → cities[]
游客人数 → peopleCount
领队信息 → leaderName / leaderPhone
司机信息 → driverName / driverPhone
```

### 行程明细（ItineraryDay）
```
每一天需包含：
  - 城市
  - 上午景点 + 时间
  - 午餐餐厅 + 电话 + 餐标
  - 下午景点 + 时间
  - 晚餐餐厅 + 电话 + 餐标
  - 酒店名称 + 地址 + 电话
  - 车程时间
  - 自费项目
  - 特别备注
```

### 酒店列表
```
每个酒店：
  - 城市
  - 酒店名
  - 地址
  - 电话
  - 入住/退房日期
```

### 费用信息
```
  - 团款总额
  - 门票预算
  - 餐费预算
  - 导游备用金
```

### 应急信息
```
  - 组团社联系人
  - 地接社联系人
  - 中国大使馆电话
  - 保险电话
```

## 六、建议的模板分类

根据欧洲线路的常见产品，预设模板类别：

| 模板类 | 典型线路 | 天数 | 城市 |
|--------|----------|------|------|
| 德奥捷经典 | 法兰克福→布拉格→维也纳→萨尔茨堡→慕尼黑 | 10天 | 5城 |
| 法瑞意 | 巴黎→琉森→米兰→威尼斯→佛罗伦萨→罗马 | 12天 | 6城 |
| 奥匈深度 | 维也纳→布达佩斯→萨尔茨堡→哈尔施塔特 | 8天 | 4城 |
| 德国全景 | 法兰克福→科隆→汉堡→柏林→慕尼黑 | 10天 | 5城 |
| 西葡 | 马德里→巴塞罗那→里斯本 | 10天 | 3城 |
| 北欧四国 | 哥本哈根→奥斯陆→斯德哥尔摩→赫尔辛基 | 10天 | 4城 |
| 巴尔干 | 卢布尔雅那→萨格勒布→贝尔格莱德→萨拉热窝 | 10天 | 4城 |

但**系统模板不是最重要的** —— 最重要的是让导游能**从自己已完成的工作一键保存为模板**。因为每个导游的做法不一样，他自己的历史行程才是最准的模板。

---

## 七、核心结论

> **模板系统的设计原则：不做「预设模板库」，做「从历史工作生成模板」。**

1. 导游完成一次工作 → 一键「保存为模板」
2. 下次出类似团 → 选模板 → 改日期/人数 → 生成
3. 模板继承所有细节：酒店、餐厅、景点顺序、餐标、备注
4. 导游只需微调，不用重填

这才是真正有用的模板系统。预设模板可以后续作为参考加上，但不是核心。
